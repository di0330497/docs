AWS 공인 솔루션즈 아키텍트 어소시에이트(SAA-C03) 시험 범위를 처음부터 순서대로 학습하는 커리큘럼. 시험 가이드의 4개 콘텐츠 도메인(보안·복원력·고성능·비용 최적화)과 In-Scope 서비스 목록을 인벤토리의 기준으로 삼고, 각 서비스의 공식 User Guide/Developer Guide 목차를 개념 단위로 흡수했다. Well-Architected 프레임워크 관점에서 아키텍처를 설계·비교하는 사고를 만드는 것이 목표다.

AWS Certified Solutions Architect - Associate SAA-C03 (현행 시험 가이드). 서비스 문서는 각 서비스의 latest 기준. SAA-C02 는 SAA-C03 으로 대체되는 이전 버전이라 도메인 구성은 C03 을 따랐다.

1시험 기준과 Well-Architected 설계 사고시험이 요구하는 4개 도메인과 Well-Architected 기반의 설계 판단 기준을 먼저 세워야 이후 모든 서비스 선택의 근거가 생긴다.42보안 설계 1: 접근 제어와 자격 증명아키텍처에서 접근 통제가 잘못되면 나머지 모든 통제가 무의미해지므로 권한·자격 증명 설계를 가장 먼저 다룬다.63보안 설계 2: 워크로드·네트워크·데이터접근 주체를 확정한 다음에는 워크로드가 실행되는 네트워크 경로와 저장 데이터를 지키는 통제를 설계한다.64복원력 설계 1: 확장과 결합 분리보안 기반 위에 부하에 따라 확장되고 서로 간섭하지 않는 구조를 만든다. 스케일링·로드밸런싱·비동기 통신·서버리스가 여기 속한다.95복원력 설계 2: 고가용성과 재해 복구확장·분리가 된 뒤에는 장애가 나도 전체가 죽지 않는 구조와, 재앙 상황에서 복구하는 전략을 배운다.56고성능 설계 1: 스토리지·데이터베이스성능 요구는 워크로드가 읽고 쓰는 저장 계층에서 절반이 결정된다. 유형별 특성과 확장·튜닝을 배운다.67고성능 설계 2: 네트워크·컴퓨팅저장 계층 다음은 트래픽이 흐르는 네트워크 토폴로지와 실제 계산을 수행하는 컴퓨팅 선택이다.48비용 최적화 설계보안·복원력·성능 요구를 충족한 뒤에는 같은 품질을 더 낮은 비용으로 충족하는 선택지를 설계한다.59확장 운영: 마이그레이션·하이브리드·자동화설계가 끝난 워크로드를 실제로 AWS로 옮기고 운영하는 도구까지 알아야 아키텍트 업무가 완결된다.5

#1문제 상황
