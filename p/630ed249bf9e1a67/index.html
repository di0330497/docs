Python 이란 무엇인가

사람이 읽는 뜻대로 적어 놓은 programs 를 컴퓨터가 그대로 실행하는, 문법이 단순하고 무엇을 해도 되는 언어인 Python 의 기본 개념과 장점·용도를 다룬다.

#1문제 상황

컴파일 언어는 코드를 고치고 다시 빌드하고 시험하는 순환이 느리다. 작은 자동화 작업 하나에도 그 순환 비용이 커서 손이 붙지 않는다.

Python 은 배우기 쉽고 강한 프로그래밍 언어다. 효율적인 고수준 자료 구조와 단순하지만 효과적인 객체 지향 접근을 함께 가진다. 우아한 문법과 동적 타이핑, 인터프리터로 실행되는 성질이 함께 있어 스크립트와 빠른 애플리케이션 개발에 알맞다. 인터프리터와 표준 라이브러리도 무료로 배포된다.

#2핵심 질문

왜 컴파일을 거치지 않고 그대로 실행하는 언어를 써도 되는가?

#3동작 예시

사람이 같은 계산을 매번 손으로 한다. 파이썬을 처음 만난 사람은 그 계산을 코드 몇 줄로 옮겨 반복해 돌린다. 결과는 즉시 나오고 틀린 줄은 고쳐 다시 돌리면 끝난다.

#4동작 과정

  1. 설치하고 이름을 알린다python.org 에서 인터프리터를 받아 두고 명령 이름으로 실행기를 부른다. 어디에 설치했는지는 옵션이다.
  2. 코드를 실행한다소스 코드를 인터프리터가 받아 곧바로 실행한다. C나 C++ 로 만든 새 함수와 자료형도 붙여 쓸 수 있다.
  3. 함께 배울 문서를 연다The Python Tutorial 이 공식 입문서이고, Python Setup and Usage 에 설치법이, About this documentation 에 문서 규약이 담겨 있다.
  4. 확인해 볼 것터미널에서 python 을 입력해 버전 문자열이 찍히고 >>> 프롬프트가 나타나는지 확인한다.

#1문제 상황

파이썬에서 다루는 정수나 문자열 같은 값은 따로 떨어진 숫자가 아니라, 값과 그 값에 쓸 수 있는 연산을 한데 묶은 덩어리다. 이 덩어리를 객체라고 부른다. Data model은 이 규칙을 정한 부분이다.

모든 데이터가 objects로 표현되므로 값마다 속성과 함수를 붙일 수 있고, 함수로 넘기거나 서로 비교할 수 있게 된다.

#2핵심 질문

#3동작 예시

#4동작 과정

  1. 값을 객체로 본다프로그램의 모든 데이터가 objects로 표현된다. 각각은 정체성·타입·값을 갖고, 정체성은 한 번 만들어지면 바뀌지 않는다.
  2. 타입으로 연산을 정한다type은 그 객체가 어떤 연산을 받게 하는지 정한다. type()은 이 타입을 반환한다.
  3. 참조와 속성을 다룬다object reference는 객체를 가리키는 관계여서 is로 정체성을 비교하고 id()로 확인한다. 여기에 인스턴스 attribute를 붙여 객체마다 다른 정보를 함께 보관한다.

Floating-Point Arithmetic: Issues and Limitations는 이 오차가 언제 생기고 rounding을 다르게 하면 결과가 달라진다는 사실을 다루는 문서다.

#2핵심 질문

왜 0.1 더하기 0.2 가 0.3 이 되지 않을까?

#3동작 예시

#4동작 과정

  1. 2진수로 저장한다컴퓨터의 실수 하드웨어는 값을 2진 분수로 나타낸다. 10진 분수인 0.625는 정확히 표현되지만 0.1 은 정확히 표현되지 않는다.
  2. 오차가 쌓인다정확히 표현되지 않은 값을 여러 번 더하거나 곱하면 오차가 커진다. 비교와 누적 계산에서 의도와 다른 결과가 여기서 나온다.
  3. 대안을 쓴다십진수를 문자열로 다루거나 Decimal을 쓰면 rounding 규칙을 정해 정확하게 계산할 수 있다. 결과 자리수도 직접 정해야 한다.
  4. 확인해 볼 것repr로 그 값이 저장된 형태를 찍어 0.1 이 길게 나오는 것을 본다.

동시 실행 세 가지

한 프로그램 안에서 여러 일을 겹쳐 처리하는 세 방식으로, 한 프로세스 안의 스레드를 쓰는 방법·프로세스를 여러 개 띄우는 방법·대기 없이 완료 통지만 다룰 때 쓰는 비동기 방식이 있다.

Concurrent Execution은 이 둘을 나눠 처리하는 세 도구를 한 곳에 모은 영역이다. 고르는 기준은 CPU를 계속 써야 하는 일인지, 기다림이 많은 일인지다.

#4동작 과정

  2. 프로세스로 나눠 돌린다multiprocessing은 별도 프로세스를 여러 개 띄운다. 프로세스 사이 자료 교환과 여러 프로세스가 일할 대상은 Queue나 Pipe로 만들고 묶음으로 쓴다.
  3. 기다림을 위임한다asyncio는 완료되면 통지되는 방식으로 대기를 없앤다. 이벤트 기반 협업 multitaking 코드로 작성한다.
  4. 확인해 볼 것threading으로 만든 예제에서 각 스레드가 찍은 줄이 실행 시각 순서대로 섞여 나타나는지 콘솔 출력으로 확인한다.

#1문제 상황

요청 하나가 늦게 끝나도 나머지는 멈추지 않아 결과 목록이 순서와 무관하게 채워진다.

  1. 모듈을 가져온다import asyncio로 표준 라이브러리 모듈을 불러온다.

11. 인터프리터 안쪽11-01

어휘 분석과 구문

파이썬 소스 코드가 실행되려면 문자 단위로 잘라 낱말(토큰)을 만든 뒤 그것들의 배치 관계인 구문 트리로 바뀌어야 하는데, 이 두 변환을 규칙으로 정해 둔 부분이다.

먼저 알아야 할 것 03-01

#1문제 상황

컴퓨터는 a = 1이라는 글자를 뜻으로 바로 읽지 못한다. 사람이 쓴 코드를 기계가 다루려면 먼저 문자 하나하나를 이름 있는 조각으로 바꿔야 한다.

Lexical analysis는 소스 텍스트를 토큰이라는 조각의 흐름으로 바꾸는 단계이고, 그 규칙은 Full Grammar specification 문서에 정리돼 있다. 결과 토큰을 토큰 뜻대로 붙여 만든 것이 구문 트리이며, 이 변환을 거친 뒤에야 프로그램이 실행된다.

#2핵심 질문

파이썬은 문자 코드를 언제 어디서 끊어 읽는가?

#3동작 예시

x = price * 2를 파이썬에 넘긴다. 어휘 분석기 lexer가 공백과 기호를 기준으로 자른 결과는 이름 x, 기호 =, 이름 price, 기호 *, 숫자 2라는 토큰이다. 이 순서를 파서 parser가 구문 트리로 조립하고, 트리가 만들어져야 코드가 실행된다.

#4동작 과정

  1. 텍스트를 해석한다Lexical analysis가 프로그램 인코딩을 UTF-8로 정하고 문자를 해독한다. 해독이 안 되면 SyntaxError가 난다.
  2. 토큰을 낸다lexer가 아직 처리하지 않은 첫 문자를 보고 다음 토큰의 종류를 정한다. 그러므로 다음 문자가 바뀌면 토큰도 달라진다.
  3. 트리를 만든다parser가 토큰을 받아 Full Grammar specification의 규칙대로 구문 트리를 세운다. 이 트리가 이어질 대상은 실행 모델(→ 11-02)이다.
  4. 확인해 볼 것파이썬 콘솔에 어휘 분석 오류를 일으키는 문자열을 넣어 SyntaxError가 뜨는지 본다.

#1문제 상황

Execution model은 이 규칙을 정한다. 프로그램은 모듈·함수 본문·클래스 정의 같은 코드 블록으로 지어지고, 각 블록은 이름이 값을 가리키는 이름 공간과 그 안에서 이름이 어떻게 정해지는지 name resolution을 정한다.

#2핵심 질문

#4동작 과정

  1. 블록을 나눈다모듈·함수 본문·클래스 정의·대화형으로 입력한 한 줄이 블록 단위다. 파일 전체나 -c로 준 문자열도 블록으로 본다.
  2. 프레임을 만든다블록 하나를 실행할 때 frame이 생긴다. frame은 그 블록의 이름 공간과 실행 위치를 함께 담는다.
  3. 이름을 묶고 살린다binding은 이름을 값에 연결하는 동작이고, scope는 그 이름이 어느 범위에서 보이는지 정한다. 한 이름을 마지막 참조가 사라지면 그 값이 모이는 객체도 함께 사라진다.
  4. 확인해 볼 것함수 안에서 값을 바꾼 뒤 함수 밖에서 그 이름을 다시 읽어 원래 값이 유지되는지 본다.

#1문제 상황

파이썬만으로는 부족한 상황이 있다. 기존에 C로 만들어 둔 라이브러리를 파이썬에서 부르고 싶고, 파이썬 계산 능력을 나만의 프로그램 안에 통째로 심고 싶다. 둘 다 표준 파이썬으로는 되지 않는다.

Extending and Embedding the Python Interpreter는 이 두 갈래를 다루는 문서 묶음이다. 파이썬 인터프리터를 그대로 가진 채 그 안에서 돌릴 수 있다.

#2핵심 질문

#3동작 예시

기존 C 라이브러리의 함수를 파이썬에서 부를 수 있게 만든 모듈을 하나 만든다. 이 모듈은 파이썬이 처음 시작할 때 메모리에 올려 지시를 받는 형태다. 파이썬 쪽 코드에서는 import 한 뒤 그 함수를 평소처럼 호출한다.

#4동작 과정

  1. 모듈을 만든다Extending Python with C or C++ 절에서 새 모듈을 컴파일하고 링크하는 방법을 설명한다. 새 함수뿐 아니라 새 객체 타입과 메서드까지 정의할 수 있다.
  2. 접근 규칙을 따른다그 안의 모든 조작 규칙은 Python/C API reference manual에 정리돼 있다. 파이썬 객체를 만들고 다루는 기준 규칙이 여기서 온다.
  3. 인터프리터를 넣는다embedding은 파이썬 인터프리터를 다른 애플리케이션 안에서 확장 언어로 쓰는 일이다. 초기화부터 실행, 정리까지의 순서를 따로 정한다.
  4. 확인해 볼 것만들어 둔 확장 모듈을 파이썬에서 import해 그 안의 함수를 호출해 본다.
