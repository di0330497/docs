AWS Certified Machine Learning - Specialty

AWS 공인 머신러닝 스페셜티(MLS-C01) 시험 범위를 처음부터 순서대로 학습하는 커리큘럼. 시험 가이드의 4개 콘텐츠 도메인(데이터 엔지니어링·탐색적 데이터 분석·모델링·ML 구현과 운영)과 In-Scope 서비스 목록을 인벤토리의 기준으로 삼고, Amazon SageMaker 중심의 공식 Developer Guide와 지원 서비스 문서 목차를 개념 단위로 흡수했다. ML 이론과 AWS 서비스 적용을 함께 배우는 순서다.

이어서 읽기
1시험 기준과 ML 문제 설정시험의 4개 도메인과 ML을 언제 쓰고 언제 쓰지 않는지 판단하는 프레임을 먼저 세워야 이후 데이터 준비·모델링·운영의 각 단계가 방향을 가진다.42데이터 저장소와 수집모델링 전에 ML 데이터가 어디에 어떻게 저장·수집되는지를 알아야 한다. 데이터 레포지토리 생성과 인제스천 파이프라인을 배운다.73데이터 준비와 탐색적 분석수집된 데이터를 모델링 가능하도록 정제하고 탐색해야 한다. 데이터 처리·특징 공학·시각화·통계 해석을 배운다.54모델 선택과 알고리즘정제된 데이터 위에서 어떤 ML 작업인지에 맞는 모델·알고리즘을 고른다. 지도·비지도·딥러닝·LLM까지의 선택 기준을 배운다.65모델 학습과 최적화모델 유형을 정한 뒤 데이터를 나누고 학습하며 하이퍼파라미터를 최적화한다. 학습 인프라 선택도 함께 다룬다.66모델 평가와 검증학습한 모델이 목표 지표를 충족하는지 오프라인·온라인 양쪽에서 검증해야 실전 배포가 가능하다.57SageMaker 기반 ML 구현이론적 평가가 끝난 모델을 SageMaker의 학습·튜닝·배포·모니터링 기능으로 실제 구현한다. 시험의 핵심 서비스 활용이다.68ML 보안과 운영구현된 ML 솔루션을 보호하고 운영하는 마지막 단계다. IAM·네트워크·암호화와 로깅·모니터링을 배운다.69관리형 AI 서비스 활용모든 문제에 커스텀 모델이 필요한 것은 아니다. 목적별 관리형 AI 서비스를 언제 쓰는지 판단하는 능력을 배운다.5
