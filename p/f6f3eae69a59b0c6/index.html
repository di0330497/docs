#2핵심 질문

#3동작 예시

squares = [x * x for x in range(5)]를 실행하면 [0, 1, 4, 9, 16]이 만들어진다. stack.append(x)와 stack.pop()으로 뒤에서 넣고 뺀다.

#4동작 과정

  1. 리스트 컴프리헨션for와 if를 한 줄에 적어 조건에 맞는 원소의 새 리스트를 만든다.

  3. 스택과 큐리스트는 append·pop으로 뒤에서 넣고 뺄 때 스택이 되고, deque로 앞쪽 작업을 효율적으로 하면 큐가 된다.
